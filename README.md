# Bodywise Safe-Use Guide

An interactive web app that checks body area suitability, guides users through patch testing, and sets up safe routines and symptom triage for Bodywise products.

## Features
- **Body Area Suitability Check**: Interactive recommendations per skin area (underarms, limbs, scalp, face, etc.).
- **Patch Test Tracker**: 24-hour countdown and triage for safe testing before application.
- **Tools**: Reapply timer, bottle usage duration calculator, and de-tan progress tracker.
- **Symptom SOS Triage**: Immediate first-aid and advice for skin irritation or burning.
- **Works on All Browsers**: Fully responsive, touch-friendly, dark/light mode supported.
